# LettiB for Windows - downloads

This repository hosts the **LettiB for Windows** installer and release notes only. It contains no source code.

**Download:** [Latest release](https://github.com/bacon-tarion/lettib-releases/releases/latest) - or go to https://www.lettib.com/download

Direct link to the newest installer: https://github.com/bacon-tarion/lettib-releases/releases/latest/download/LettiB-Setup.exe

The beta isn't code-signed yet. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Each release lists the SHA-256 of the installer so you can check it.

Questions: visit https://www.lettib.com
